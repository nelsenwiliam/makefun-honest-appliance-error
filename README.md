[**The Funniest Honest Appliance Error**](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450):
the funniest honest error message an appliance could show.

`main.py` (Python 3.13, pure standard library) writes one line to
`/output/entry.txt`:

> Error E04: Drain pump blocked by a coin. Again. Please stop feeding me your pockets.

A drain pump blocked by a coin is a real washing-machine fault — and the
machine is done pretending the coins got there by themselves. Ten
candidates were scored against the judge's brief (honest fault, real joke,
honesty, machine voice, economy); this one won on all five.
